# 솔로 서바이벌 · 황무지의 끝에서

Javier Loustaunau의 **Solo Survival** 원본 규칙과 사건 자료를 바탕으로 제작한 비공식 한국어 웹게임입니다.

외부 API나 언어 모델 없이 브라우저에서 진행합니다. 52개 사건, 6면체 주사위 두 개, 식량·부상 관리, 손패 보정, 성장, 승패와 자동 저장을 제공합니다.

## 실행

- 웹 연결 대상: [solosurvival.duckdns.org](https://solosurvival.duckdns.org)
- 로컬 실행: Node.js가 있는 Windows에서 `시작.cmd`를 실행합니다.
- 저장은 브라우저와 접속 주소마다 별도로 유지됩니다. 공개 주소와 로컬 주소의 저장은 공유되지 않습니다.

## 규칙과 검증

- [규칙 처리 기준](규칙_처리기준.md): 원작의 모호한 표현에 적용한 해석과 카드별 효과
- [실행 안내](실행안내.md): 로컬 실행과 저장 방법
- [제작 기록](제작기록.md): 자동 검사와 브라우저 플레이의 검증 범위
- 검사 명령: `node --test engine.test.cjs`

원작 출처: [제작자 공식 배포 페이지](https://javierloustaunau.itch.io/solo-survival)

공식 한국어판이 아니며 원작 명칭·규칙·사건의 권리는 원저작자에게 있습니다. 원본 PDF·DOCX와 원문 확인 이미지는 이 저장소에 포함하지 않습니다. 공식 배포 페이지에서 웹 재배포에 대한 별도 이용 허락은 확인하지 못했으며, 이 저장소는 원작 콘텐츠에 대한 새로운 이용 허락을 부여하지 않습니다.

## 배포 구성

GitHub Pages의 배포 소스를 `main` 브랜치의 루트(`/`)로 설정하고, 사용자 지정 도메인을 `solosurvival.duckdns.org`로 연결합니다. `CNAME`에 도메인을 기록하고 `.nojekyll`로 정적 파일을 그대로 제공합니다. 인증서 발급 후 HTTPS를 강제합니다.

DuckDNS 주소는 GitHub Pages를 가리켜야 합니다. 로컬 서버를 인터넷에 개방하거나 개인 PC의 공인 IP로 연결할 필요는 없습니다.
